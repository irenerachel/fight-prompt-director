# 动作摄影机指南

本文件提供通用摄影术语和选镜方法，不提供可直接套用的固定剧情句。摄影机需要服务动作可读性，不能代替动作本身。

## 镜头句式

每条运镜尽量写全六项：

```text
〔景别或焦段〕 + 〔机位高度与角度〕 + 〔运动速度〕 + 〔摄影机方向〕 + 〔跟随对象〕 + 〔本镜职责〕
```

示例格式中的占位符需要按当前场景填写：

```text
〔焦段〕低机位中景，摄影机以〔速度〕沿〔方向〕跟随〔角色或物体〕，让〔接触、距离或结果〕保持清楚。
```

## 镜头职责

| 职责 | 画面需要回答的问题 | 可选方式 |
|---|---|---|
| 建立空间 | 人物、出口、障碍分别在哪里 | 大全景、俯拍、侧向全身景 |
| 追随位移 | 谁朝哪里移动，速度怎样变化 | 平行跟拍、侧后跟拍、贴地跟拍 |
| 看清接触 | 动作是否命中，接触点在哪里 | 侧向中景、短促特写、动作匹配切 |
| 表达反制 | 主动权怎样发生变化 | 反应近景、轴线同侧切入、回接双人景 |
| 表达失衡 | 受力方向和身体姿态怎样改变 | 倾斜、短幅翻滚、沿受力方向追随 |
| 展示弹道 | 释放者、路径和目标怎样关联 | 过肩景、长焦压缩、高位距离景 |
| 揭示结果 | 谁获得位置优势，环境发生什么变化 | 快速后拉、升镜、遮挡物移开 |
| 稳定收尾 | 结果清楚后保留哪些运动 | 固定构图、稳定跟随、慢速轨道移动 |

四镜以上的片段尽量覆盖不同职责。相邻镜头连续执行同一职责时，需要有明确理由。

## 按动作阶段选择镜头

### 起动

- 用全景或中景同时建立角色、路线和第一步动作。
- 需要速度时，摄影机沿主角前进方向移动。
- 需要空间判断时，使用高位或侧向机位。
- 开场镜头内已经发生有效动作，避免只拍站立或缓慢观察。

### 距离变化

- 横向移动使用平行跟拍，保留双方间距。
- 折线逼近使用高位景，交代掩体与路线。
- 高度变化使用低机位起跳加高位落点承接。
- 改变机位时保持屏幕方向和人物左右关系。

### 接触与格挡

- 接触前用能够看见双方身体的景别。
- 接触瞬间可以短促推近、轻微震动或切到侧向特写。
- 接触后立即承接受力、位移和环境结果。
- 不在接触即将发生时用遮挡或过近特写藏住动作。

### 远程攻击

- 释放前交代武器、手部或能量来源。
- 用过肩景或长焦景同时建立射手、路径和目标。
- 关键投射物可以短暂追随，普通投射物优先直接切到落点。
- 命中或落空后回到释放者，交代换位、装填或资源变化。

### 反制

- 反应镜头保留上一镜的视线方向和动作状态。
- 切到对手侧时维持轴线，随后回接双人景确认接触。
- 特写只拍正在变化的状态，例如握力、重心、视线或武器角度。

### 受击与结果

- 摄影机沿受力方向承接失败方的移动。
- 先拍身体接触部位，再拍墙面、地面或道具反馈。
- 结果明确后拉开景别，同时保留尘土、碎片、衣摆或其他余波。

## 三档强度搭配

| 阶段 | 高强度 | 中间型 | 慢节奏 |
|---|---|---|---|
| 起动 | 低机位快速跟随 | 中景定向后切入 | 长镜建立路线 |
| 位移 | 贴地或侧后跟拍 | 平行跟拍 | 轨道移动 |
| 接触 | 动作匹配切、短促推近 | 接触特写加双人回接 | 侧向全身景 |
| 反制 | 轴线同侧快速切入 | 反应近景 | 长镜内部改变构图 |
| 远攻 | 落点切回、短暂弹道追随 | 过肩景、高位距离景 | 长焦保持路径关系 |
| 受击 | 沿受力方向快速追随 | 中景承接位移 | 长镜看完整结果 |
| 收尾 | 快速拉开后稳定 | 中景转全景 | 稳定轨道离开 |

极速版补充：三档强度都优先使用快速跟随和摇甩衔接，慢节奏不使用慢速轨道开场，特写改成 0.4 至 0.8 秒的短推近，默认不使用慢动作。

## 连续性记录

每次切镜前记录至少以下信息：

- 人物左右位置
- 面朝方向和身体姿态
- 运动方向与速度
- 武器所在手、角度和完整状态
- 弹药、能量或道具数量
- 对手是否还能行动
- 场景损伤和移动物体
- 仍在持续的尘土、火花、液体或光效

切镜只改变观看位置。已经发生的事件不能因机位变化被重置。

## 声音配合

- 普通镜头选择一到三个与动作同序的同步声。
- 长镜头可以增加脚步、衣料、武器和环境声层次。
- 极短镜头只保留一个最重要的接触重音。
- 风、雨、机器底噪和音乐属于持续声场，放在全局说明中。
- 所有具体音效都需要在画面或场景中找到来源。

## 常见误用

- 连续快速切镜导致左右位置交换
- 摄影机运动过多，身体动作被遮住
- 每次命中都使用震动，画面失去层次
- 普通投射物全程跟随，压缩了角色反应时间
- 慢动作覆盖完整倒地过程，节奏被拖散
- 收尾只剩静止姿势，没有保留任何环境运动
