# 动作结构与原创示例

本文件提供七类动作场景的结构骨架。所有示例均为公开版重新设计的虚构情境，只用于说明编排方法。生成正式提示词时，需要按用户提供的角色、武器、空间和结果重新设计。

## 通用动作设计表

写任何类型前，先完成下面的信息：

| 项目 | 需要回答的问题 |
|---|---|
| 完成条件 | 怎样才算结束这场动作戏 |
| 角色差异 | 每名角色擅长什么距离和动作方式 |
| 空间轴线 | 谁从哪里开始，朝哪个方向移动 |
| 资源 | 武器、弹药、能量或可用环境介质有哪些 |
| 主动权变化 | 谁在什么时刻取得或失去优势 |
| 连续状态 | 位置、朝向、速度、武器和损伤怎样继承 |
| 结束画面 | 结果如何被镜头明确看见 |
| 速度档位 | 本次是标准版还是极速版 |

## 标准版与极速版的时间密度

速度是独立于强度的一条轴。极速版不新增强度方案，而是让高强度、中间型、慢节奏三套骨架同时变快。以 15 秒为基准：

| 项目 | 标准版 | 极速版 |
|---|---|---|
| Seedance 时间块 | 约 4 段，每段 3 至 4 秒 | 5 至 6 段，每段 2 至 3 秒，首尾相接 |
| 高强度 | 现有交锋与镜头数量 | 7 至 9 次交锋、约 16 至 22 个微动作、6 至 9 个镜头 |
| 中间型 | 现有交锋与镜头数量 | 6 至 8 次交锋、约 12 至 16 个微动作、5 至 7 个镜头 |
| 慢节奏 | 现有交锋与镜头数量 | 5 至 7 次交锋、约 10 至 14 个微动作、3 至 4 个镜头或高密度一镜到底 |
| 起手 | 第一个有效动作约 0.3 秒内 | 第一个有效动作 0.15 秒内 |
| 纯恢复动作 | 最长约 0.7 秒 | 最长 0.3 秒 |
| 动作特写 | 约 0.8 至 1.5 秒 | 0.4 至 0.8 秒 |
| 慢动作 | 按需使用 | 默认不用，决定性命中最多一次 0.15 至 0.3 秒 |

极速版的微动作总量比标准版增加约 30% 至 40%。用户没有单独要求预告片式密度时，不要冲到 20 至 25 个微动作，也不要用 10 至 14 个碎切代替交锋。骨架阶段数量不变，只是每个阶段的动作更密、时间更短：慢节奏去掉长起势、长呼吸和长环绕，仍然保留最完整的发力与受力过程。因果链、角色动作差异、弹道与资源连续性在极速版中同样必须成立。

## 1. 单人突围

适合单一主角面对机关、坍塌、追击装置或自然威胁。威胁需要逐步改变形态，主角始终朝明确出口推进。

### 骨架

1. 建立路线、出口和主角当前状态
2. 第一种威胁迫使主角改变步法或高度
3. 第二种威胁封住原路线，主角利用环境开辟新通道
4. 最后障碍检验前面建立的动作能力
5. 主角抵达、脱离或被迫停在清晰位置

### 原创示例：冷库货架突围

```text
冷库检修员从画面左后方朝右前方的红色安全门移动。自动货架依次发生侧滑合拢、顶层冰箱坠落和地面冷雾遮挡。检修员先贴地穿过货架下层，再踩上倾斜托盘改变高度，最后用肩部撞开已经结霜的应急推杆。每次货架移动都留下新的通道宽度，掉落的冰箱与碎冰保持原位。结尾安全门完全打开，检修员跌入门外暖光区域，冷雾仍从脚边向外涌出。
```

## 2. 双人攻防

适合两名角色使用近战、远攻或混合距离交锋。核心是主动权变化和距离争夺。

### 骨架

1. 为双方设置不同优势距离
2. 第一轮由一方迫使另一方离开舒适距离
3. 被压制者通过地形、武器或假动作改变局面
4. 第二轮交换位置或朝向
5. 结束时明确谁获得空间、时间或行动优势

### 原创示例：潮位塔缆索对抗

```text
潮位塔维修员使用短柄钩，擅长贴近后勾拉重心；测绘员使用可伸缩测距杆，保持中距离点压和封路。测绘员从右侧栏杆前连续点向维修员肩线，迫使对方向左退。维修员让第二次点压擦过外套，短柄钩扣住测距杆中段，沿顺时针方向带动双方绕立柱换位。测绘员松开前手缩短杆身，用杆尾抵住维修员髋部重新拉开距离。结尾两人隔着立柱分处画面两侧，缆索仍在脚下摆动，双方武器各保持一件。
```

## 3. 远程能量对抗

适合法术、装置、声波或能量路径之间的远程对抗。需要说明能量来源、传播路径、接触结果与环境影响。

### 骨架

1. 展示双方不同的释放条件
2. 第一轮能量改变场景或迫使一方移动
3. 防守方通过折射、吸收、偏转或切断来源反制
4. 第二轮改变传播路径或释放位置
5. 结果落在可见目标或无人环境中

### 原创示例：回声穹顶频率争夺

```text
圆形声学实验厅内，A 通过双手旋转金属音叉形成窄束蓝色声纹，B 通过脚下四块共振板释放橙色环形波。A 的第一束声纹沿地面直线推进，B 踩下右后方共振板，让环形波从侧面推偏声纹，墙面吸音棉被掀起一条弧线。A 随即移动到中央圆台，改变音叉角度，让第二束声纹先击中玻璃反射板，再折向 B 左侧空地。B 关闭两块共振板，将剩余能量收束成半圆屏障。结尾两股能量在无人区域相消，顶部悬挂的测试丝线沿冲击方向持续摆动。
```

## 4. 一人对多人

适合一名主角面对多个主动威胁。每个对手需要有位置和行为差异，离场或倒地状态需要持续保留。

### 骨架

1. 用全景交代主角与每名对手的位置
2. 让对手按照不同方向和节奏发起动作
3. 主角利用一个对手的位移阻挡另一个对手
4. 画面保留已经退出战斗的人与物
5. 结尾明确剩余人数和主角去向

### 原创示例：悬索仓库护送

```text
货运员右手握一把折叠伞，护送装有玻璃样本的银色手提箱穿过悬索仓库。四名磁靴守卫分别从前方吊桥、左侧货架、右后方升降台和上层横梁逼近。货运员先撑开伞面挡住前方抛来的软索，让软索绕住右侧立柱，再收伞转身压低左侧守卫的手腕，使其撞向正从升降台落下的第三人。上层守卫跳下时，货运员把手提箱滑到安全线内，利用空出的左手拉动悬索，让吊桥横移隔开双方。结尾四名守卫的位置清晰可见，手提箱保持关闭且没有复制。
```

## 5. 人兽对决

适合体型、速度和受力尺度差异明显的双方。小体型角色依靠选位与时机，大体型生物依靠范围、地形改变和惯性。

### 骨架

1. 建立体型比例和安全距离
2. 巨兽用一次大范围动作改变地面或遮挡
3. 主角通过侧翼、高度或弱点取得短暂机会
4. 巨兽调整攻击方式形成反转
5. 结果通过倒塌、退让、脱离或环境变化呈现

### 原创示例：盐湖玻璃壳兽

```text
盐湖勘探员驾驶单轮滑行器，从画面右侧绕向透明甲壳兽的后足。甲壳兽前肢拍落，盐壳从接触点向外裂成扇形，勘探员借裂缝边缘抬高滑行器，越过冲来的盐浪。勘探员把一枚声学标记器贴在后足关节，甲壳兽随即转身甩尾，迫使她俯身贴近甲壳下方。标记器发出脉冲后，甲壳兽因不适退向湖心，透明外壳映出逐渐远离的红灯。结尾勘探员停在原裂缝外侧，甲壳兽仍朝湖心移动，地面的扇形裂纹保持不变。
```

## 6. 单人演武

适合无对手的武器、身体或能力展示。动作需要形成完整闭环，每个阶段拥有不同空间落点。

### 骨架

1. 起势同时启动镜头与身体运动
2. 横向、纵向和高度变化至少各出现一次
3. 武器或道具始终保持唯一
4. 环境介质响应动作方向
5. 收势回到稳定、可读的位置

### 原创示例：灯塔链钩演武

```text
灯塔守夜人站在旋转透镜外圈，右手持唯一一枚铜制链钩。她先沿顺时针方向踏出半圆，链钩贴地扫过积水形成细长弧线；随后拉紧链条让钩头绕过扶手，借回拉力量跃上两级铁梯；落地时身体向左旋转，链条从肩后越过并收回掌中。摄影机持续沿透镜外圈平行移动，不切镜头。结尾她面向入口收拢链条，透镜光束仍按照原速度扫过墙面。
```

## 7. 风格化材质动作

适合刺绣、纸雕、木偶、陶土、像素或其他强媒介风格。动作需要遵守材料能弯曲、折叠、断裂或移动的方式。

### 骨架

1. 先定义材质、关节和摄影机限制
2. 所有角色、武器和特效使用同一媒介逻辑
3. 每次接触产生符合材料的反馈
4. 镜头避免破坏平面或舞台规则
5. 收尾保留线头、折痕、碎屑或结构变化

### 原创示例：绣框上的丝线追逐

```text
整条视频呈现为真实刺绣。深绿色丝线骑手从绣框左侧沿山纹向右奔跑，金色丝线追兵从下方河纹斜向上拦截。两人的四肢由分段针脚连接，只能沿布面滑移、折转和短距离跃线。绿色骑手用线制短杖挑起一段松散蓝线，蓝线在接触后形成弧形障碍；金色追兵用剪刀形针脚剪断其中一端，断线保持卷曲。摄影机始终正对绣布，只做平面平移和轻微推近。结尾绿色骑手抵达右上角塔纹，所有断线和新针孔继续保留。
```

## 正式生成前检查

- 示例中的角色、场景和动作没有被直接带入用户成稿
- 每名角色的动作方式来自当前身份、体型、武器和目标
- 每轮交锋都包含回应与位置结果
- 远程攻击交代来源、路径、落点和后续资源状态
- 环境破坏与受力方向一致
- 结束画面兑现了开头设定的完成条件
- 没有添加知名角色、品牌道具或用户未提供的剧情设定
- 极速版的时间块、交锋数量、镜头数量和特写时长都落在上表范围内，密度不是靠无来源闪切堆出来的
